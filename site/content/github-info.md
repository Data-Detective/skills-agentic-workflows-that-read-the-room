## Recent GitHub news

- **Stacked pull requests are generally available (Oct 6, 2026):** Split large changes into smaller, independently reviewable pull requests that merge together, with approvals preserved on rebase. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available).
- **GitHub Actions workflow lockfiles in public preview (Oct 14, 2026):** Pin action dependencies to exact commits with the `gh actions-lock` extension so moved tags or branches can't change what runs. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview).
- **Some Git over HTTPS may temporarily require authentication (Oct 19, 2026):** During unusual traffic, unauthenticated clones and fetches of public repos may need authentication; in Actions, use the built-in `GITHUB_TOKEN`. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-19-some-git-over-https-may-temporarily-require-authentication).
