## Recent GitHub updates

- **Stacked pull requests are generally available (Oct 6, 2026):** Break large changes into smaller pull requests that are reviewed independently and merged together. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **GitHub Actions workflow lockfiles in public preview (Oct 14, 2026):** Lock action dependencies to exact commits so a moved tag or branch can't change what your workflow runs. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/).
- **Dynamic workflows in Copilot CLI and the Copilot app (Oct 1, 2026):** Define multi-agent orchestrations in code for repeatable, observable Copilot tasks. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app/).
